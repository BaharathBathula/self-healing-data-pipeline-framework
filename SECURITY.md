# Security Policy

## Supported Versions

The Self-Healing Data Pipeline Framework is actively maintained for current public releases.

| Version | Supported |
| ------- | --------- |
| 1.x.x   | ✅ Yes |
| < 1.0   | ❌ No |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### Preferred Method

Open a private security advisory through GitHub Security Advisories or contact the maintainer directly through GitHub.

### Please Include

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

---

## Response Commitment

Reported issues will be reviewed as promptly as possible. Valid security findings may result in:

- dependency upgrades
- code fixes
- workflow hardening
- documentation updates

---

## Scope

This policy applies to:

- source code
- GitHub Actions workflows
- dependencies
- deployment assets
- example scripts

---

## Best Practices

Users are encouraged to:

- keep dependencies updated
- review workflows before use
- avoid exposing secrets in repositories
- test changes in non-production environments

---

## Disclosure Policy

Please avoid publicly disclosing security issues until they have been reviewed and mitigated.
